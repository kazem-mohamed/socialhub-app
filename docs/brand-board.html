Rules

Display tracking is always negative (−.045em).

Body never exceeds 68 characters.

Mono is never used for prose — only notation.

Playfair is italic-only. There is no roman weight in this system.

Bricolage Grotesque is reserved for the wordmark (§01) — never used in UI text.

04

The aura system

Vermilion is the brand's colour. The aura is the user's. Each handle hashes to a hue anchored within 80° of vermilion, so ten thousand distinct auras still read as one family.
